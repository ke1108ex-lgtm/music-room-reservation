# 音楽室予約サイト

このリポジトリは、音楽室の予約サイトの簡易プロトタイプです。

## 仕様
- 1バンドあたり最大2枠まで予約可能
- 音楽室は Room A / B / C
- 時間帯は 09:00〜20:00 の1時間ごと
- ブラウザ内で予約データを保持（localStorage）

## 使い方
1. `index.html` をブラウザで開く
2. バンド名・音楽室・日付・時間帯を入力して予約する
3. すでに予約されている時間帯は選べない
4. 同じバンドが同じ音楽室・日付で2枠を超えると予約不可

## ファイル構成
- `index.html` : 画面の基本構造
- `styles.css` : デザイン
- `app.js` : 予約ロジック
